PREVIEW
Open index.html in a modern browser. Keep the assets folder beside index.html.

PUBLISH FREE WITH NETLIFY
1. Extract this ZIP on your computer.
2. Open https://app.netlify.com/drop in your browser.
3. Sign in or create a free Netlify account (do not share your password with anyone).
4. Drag the extracted nisha_k_portfolio folder onto the Netlify Drop area.
5. Wait for Netlify to finish publishing. It will show a public HTTPS URL ending in netlify.app.
6. Open that URL in a private/incognito browser window and verify the page and all three images.
7. Share that public URL with your professor.

UPDATING LATER
Edit index.html with a text editor or VS Code. Keep the three image files in the assets folder, preserving their filenames. To publish changes, drag the updated site folder to Netlify again or connect a Git repository in Netlify.

IMPORTANT
This package is prepared for deployment but has NOT been published to a public hosting account. No live public URL has been created or verified yet.
